# FuckHyper

面向小米 HyperOS 的增强模块，提供键盘内联填充、自定义卡面、主题调整、部分遥测限制，以及通行密钥和 FCM 推送相关功能。界面采用 Miuix。


## 引用与致谢

相关功能来源与参考项目如下，感谢相关作者与贡献者：

- [XiaoAI-Inline](https://github.com/nairain233/XiaoAI-Inline/) 为本项目提供超级小爱键盘内联填充功能。
- [FuckMiuiThemeManager](https://github.com/gsymasd/FuckMiuiThemeManager/) 主题管理相关功能参考。
- [HyperCeiler](https://github.com/ReChronoRain/HyperCeiler) 部分 HyperOS 系统功能参考。
- [HyperPasskey](https://github.com/Howard20181/HyperPasskey) 通行密钥相关功能参考。
- [HyperOS_FCM_Live](https://github.com/Howard20181/HyperOS_FCM_Live) FCM 推送连接与唤醒相关功能参考。
